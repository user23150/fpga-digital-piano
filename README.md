# FPGA 实时多音色合成电子乐器引擎

> 基于高云 GW2A-18 FPGA 的 8 声部复音电子琴，纯硬件实时合成，端到端延迟约 2.7 ms。

## 一、项目概述

本项目实现一台**完全用 FPGA 硬件逻辑实时合成**的电子琴：

- **不依赖 CPU / 软件**：DDS 振荡、包络、混音、效果器、I2S 全部为并行硬件逻辑
- **8 声部复音**：8 路独立 DDS + 独立 ADSR，可同时发声
- **4 种乐器预设**：钢琴 / 风琴 / 弦乐 / 木琴（覆盖 4 种基础波形）
- **3 维演奏表情**：力度（ADC 电位器）、滑音（Glide）、颤音（Vibrato）
- **3 种音频效果器**：延迟（Echo）、混响（Reverb）、合唱（Chorus）
- **演奏可视化**：4 路 LED 音区指引 + 自动播放旋律跟随
- **自动演奏**：音阶 / 小星星 / 琵琶曲（东船与西舫）/ 音准测试
- **录音回放**：按键事件录制（20 ms 采样，40 秒容量），可原样回放

## 二、系统架构

```
                    ┌──────────────────────────────────────────┐
 4×4 矩阵键盘 ──────▶│ 键盘扫描 (250µs/行, 三态)                 │
                    │        ↓ 16 位按键位图                    │
 旋转电位器 ────────▶│ ADS1115 (I2C 16bit) ──▶ 力度曲线 (平方律) │
                    │        ↓                                  │
                    │  乐器预设选择 (键 8~11)                    │
                    └──────────────────┬───────────────────────┘
                                       ↓ 门控 + 频率控制字
                    ┌──────────────────────────────────────────┐
                    │  8× Voice (DDS 32bit + 指数 ADSR + 波形)  │
                    │    · 滑音 (Glide)   · 颤音 (6Hz LFO)       │
                    │    · 起音瞬态噪声 (LFSR)                   │
                    └──────────────────┬───────────────────────┘
                                       ↓ 8 路 PCM
                    ┌──────────────────────────────────────────┐
                    │  混音 (19bit 求和) + 饱和限幅              │
                    │        ↓                                  │
                    │  效果器: 延迟 / 混响 / 合唱 (BRAM 延迟线)  │
                    │        ↓                                  │
                    │  主音量 (16 档) → I2S 主模式 (48kHz)      │
                    └──────────────────┬───────────────────────┘
                                       ↓ BCK / LRCK / DIN
                              PCM5102A (I2S DAC)
                                       ↓ 模拟
                              PAM8403 (D 类功放)
                                       ↓
                                 8Ω 扬声器
```

## 三、关键技术指标

| 项目 | 指标 | 说明 |
|---|---|---|
| **复音数** | **8** | 8 路独立 DDS + ADSR，全并行 |
| **采样率** | **48.000 kHz** | 相位累加小数分频（K=3817749），误差 < 0.001% |
| **DDS 位宽** | 32 bit | 频率分辨率 **0.011 Hz** |
| **音准基准** | A4 = 440 Hz | FWORD = 39,370,534（精确值） |
| **延迟** | **≈2.7 ms** | 键盘 1ms + I2S 0.67ms + DAC 1ms |
| **音域** | C4 ~ C5 | 8 键一个八度（十二平均律） |
| **音色** | 4 种 | 钢琴(锯齿) / 风琴(方波) / 弦乐(三角) / 木琴(正弦) |
| **效果器** | 3 种 | 延迟 85ms / 混响 21ms 反馈3/4 / 合唱 12.5ms+LFO |
| **资源占用** | LUT 52% / DSP 69% / BSRAM 14% | GW2A-18（20736 LUT） |
| **时序** | 27 MHz，0 警告 | 已加 SDC 约束 |

## 四、硬件连接

### 4.1 核心器件

| 器件 | 型号 | 作用 |
|---|---|---|
| FPGA 开发板 | BigPig-Bro（GW2A-LV18PG256C8/I7） | 主控，27 MHz 晶振 |
| 音频 DAC | PCM5102A 模块 | I2S → 模拟立体声 |
| 功放 | PAM8403 | 2×3W D 类功放 |
| 扬声器 | 8Ω 0.5W | 发声 |
| ADC | ADS1115（16 bit，I2C） | 力度采集 |
| 输入 | 4×4 矩阵键盘 + 旋转电位器 | 音符 / 力度 |
| 指示 | 4× 普通 LED（+限流电阻） | 音区指引 |

### 4.2 引脚分配（`src/day3.cst`）

| 信号 | 引脚 | 说明 |
|---|---|---|
| `clk` | H11 | 27 MHz 晶振 |
| `key_row[3:0]` | D11 / J11 / A9 / E14 | 键盘行（三态扫描） |
| `key_col[3:0]` | D16 / C9 / L12 / F10 | 键盘列（内部上拉） |
| `key_t6` | T6 | 板载按键（播放模式切换） |
| `i2s_bck` | K11 | I2S 位时钟 3.072 MHz |
| `i2s_lrck` | K13 | I2S 声道时钟 48 kHz |
| `i2s_din` | N8 | I2S 数据 |
| `i2c_sda` | H12 | ADS1115 SDA |
| `i2c_scl` | G11 | ADS1115 SCL |
| `led[0]` | T12 | 音区 1（哆/唻） |
| `led[1]` | P13 | 音区 2（咪/发） |
| `led[2]` | R11 | 音区 3（唆/拉） |
| `led[3]` | R13 | 音区 4（西/哆高） |

**⚠️ LED 必须串联 220Ω~1kΩ 限流电阻**，否则可能损坏 IO。

## 五、操作说明

### 5.1 键盘布局

```
行0:  哆(C4)   唻(D4)   咪(E4)   发(F4)
行1:  唆(G4)   拉(A4)   西(B4)   哆(C5)
行2:  钢琴     风琴     弦乐     木琴      ← 乐器预设
行3:  音量+    音量−    效果器   颤音/录音
```

### 5.2 功能键

| 按键 | 短按 | 长按（>0.5s） |
|---|---|---|
| **T6** | 播放模式循环：音阶 → 小星星 → 琵琶曲 → 音准测试 → 停止 | — |
| **S15（效果器）** | 效果循环：关 → 延迟 → 混响 → 合唱 | — |
| **S16** | 颤音开关 | 录音 / 回放循环（有提示音） |

### 5.3 提示音（状态反馈）

| 事件 | 提示音 |
|---|---|
| 开始录音 | 高音 880 Hz |
| 开始回放 | 中音 440 Hz |
| 停止录音/回放 | 低音 220 Hz |

## 七、构建与烧录

### 7.1 环境

- **Gowin EDA** V1.9.11.03（Education 版即可）
- **Python 3**（生成查表代码）

### 7.2 编译

```bash
# 方式一：命令行
gw_sh build.tcl

# 方式二：双击 1_编译.bat
```

### 7.3 烧录

```bash
# SRAM 模式（掉电丢失，用于调试）
programmer_cli --device GW2A-18C --run 2 --fsFile impl/pnr/day3.fs
```

**掉电保存**（GW2A 为 SRAM 型 FPGA，需烧外部 SPI Flash）：在 Gowin Programmer 中选择 `External Flash Mode`，加载 `impl/pnr/day3.fs` 后烧录。

> 注意：GW2A 系列**没有内嵌 Flash**（`embFlash` 操作会失败），配置数据必须存外部 SPI Flash。

## 八、设计亮点

| 亮点 | 说明 |
|---|---|
| **三态矩阵扫描** | 未扫描行输出**高阻**而非高电平，解决"同列多键同时按下导致短路"（否则列线被 0V/3.3V 同时强驱） |
| **精确 48 kHz** | 用**相位累加小数分频**（K = 3817749）而非整数分频，误差 < 0.001% |
| **指数 ADSR** | `env - (env >> N)` 实现指数衰减，比线性衰减更接近真实乐器 |
| **起音瞬态噪声** | LFSR 噪声在起音瞬间注入（约 30ms 衰减），模拟钢琴锤击/拨弦质感 |
| **滑音与曲目解耦** | 键盘弹奏有滑音表情；曲目播放时跳过滑音（音高立即到位），否则旋律会"飘" |
| **效果器延迟线** | BRAM 存储 + 同步读，反馈系数决定"回声"还是"混响" |
| **录音事件化** | 不录 PCM（3.8MB），而录"按键事件"（20ms 采样，2KB），压缩 1900 倍 |
| **LED 音区指引** | 4 灯对应 4 个音区，键盘按键与自动播放旋律都能跟随 |

## 九、已知限制

| 限制 | 说明 |
|---|---|
| 音域一个八度 | 键盘 8 键为 C4~C5；自动播放可另用更宽音域（待扩展） |
| 矩阵键盘鬼键 | 3 键呈"L 形"时会出现幻影键（矩阵键盘固有特性，每键加二极管可根治） |
| OLED 未启用 | SSD1306 驱动代码已就绪但调试未通过，当前用 LED 替代可视化 |
| 声部分配为固定映射 | 键 i → 声部 i（8 键 8 声部等效，未做动态分配） |
